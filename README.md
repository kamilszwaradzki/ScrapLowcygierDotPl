# ScrapLowcygierDotPl

Aplikacja desktopowa w .NET Core, która automatycznie pobiera z lowcygier.pl aktualne linki do gier dostępnych za darmo i wyświetla je w wygodnej liście.

## Funkcjonalności
- Wyświetlanie listy gier z tytułami i linkami
- Otwieranie wybranego linku w przeglądarce jednym kliknięciem

## Technologie
- .NET 6 / .NET 7 / .NET 8
- C#
- HttpClient + HtmlAgilityPack
- WPF – interfejs graficzny
- async/await

## Jak uruchomić
1. Sklonuj repo
2. dotnet restore
3. dotnet run
